# Sameer Shaik — Product Portfolio

A responsive, buildless portfolio covering product thinking, enterprise SaaS experience, and applied AI.

## Run locally

Serve the `dist/` directory using a static HTTP server, or open root `index.html` in a browser with `dist/` alongside it.

## Deploy on Vercel

Import this repository and use `main` as the production branch. The included `vercel.json` selects `dist/` as the output directory, with no framework, build command, or install step required.

## Source

- `dist/index.html`: page sections and professional copy.
- `dist/style.css`: visual system and responsive layouts.
- `dist/app.js`: projects, case studies, tabs, filters, theme and navigation.
- `dist/motion.css` and `dist/motion.js`: personal opening, chapter portraits, transitions, scroll motion and motion preferences.
- `dist/assets/`: artwork and PDF decks.
- `index.html`: bundled local convenience copy; regenerate after source edits.

## Features

An illustrated personal opening in cream, sage and terracotta with four interactive portrait chapters, a swipeable project shelf with arrow and keyboard controls, count-up impact metrics, animated artwork and selection panels, a personal closing postcard, followed by prototype-inspired CompassLoop and Attune showcases, interactive skills and career sections, case-study dialogs, scoped professional metrics, an illustrated cricket playbook, anime influences, and a contact section. Keyboard navigation, reduced-motion support, mobile quick navigation, and light/dark themes are included.

## Content and evidence

Professional metrics were supplied by Sameer: 14,000+ customer interactions across Tekion and Citrix; 97% CSAT across 2,500+ responses; 150+ internal-agent users; eight internal agents built at Tekion, including an agent supporting leadership workflows. Concept UI uses labelled demo data. Research findings and proposed targets are distinguished from launched-product outcomes.

Cricket artwork was adapted from Sameer’s supplied image references using the built-in image generation tool. The displayed artwork has no source-link captions, as requested. Anime artwork is original fan illustration; captions are personal interpretations.

## Verification

JavaScript syntax, HTML identifiers, local assets and links checked. Browser layout checks passed at 320, 390, 768 and 1440 CSS pixels with no horizontal page overflow. Tabs, filters, keyboard navigation, and case-study dialogs were exercised. The revised contact section was visually checked on mobile.
